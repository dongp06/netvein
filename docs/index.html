Engine Core

Six Pillars of NetVein

A unified architecture combining DevTools Protocol control with a dedicated wire-level proxy daemon.

Single-Session CDP Bridge

Launches and binds Chrome, Edge, or Brave on debug port 9222. Keeps tab states, sessions, and memory breakpoints persistently alive across repeated tool calls.

Autonomous Capture Kit

Pause matching network exchanges in flight. Mutate request headers, signature hashes, or body JSON before dispatching, and replay with dot-path schema diffing.

Wire-Level Traffic Daemon

A standalone loopback MITM proxy intercepts everything on the network stack. Subprocesses, background scripts, and curl invocations route through transparently.

AST & Crypto Analysis

Traverse minified JavaScript ASTs with Acorn. Automatically score candidate HMAC/AES signing algorithms, hook SubtleCrypto, and discover hidden API routes.

Stealth & Evasion

Defeat Cloudflare Turnstile, Akamai, DataDome, and GeeTest. Patch WebGL, Audio, Canvas, and neutralize runtime anti-debug loops automatically.

Project Workspace (.netvein)

Per-project state discovered upward from your repository. Automatically records streaming JSONL traffic logs, keeps configuration defaults, and preserves analysis across crashes.
